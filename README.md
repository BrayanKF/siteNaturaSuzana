# 🌿 Natura Suzana | Landing Page de Produtos

## 📌 Sobre o Projeto
Este projeto consiste no desenvolvimento de uma landing page voltada para apresentação de produtos, com foco em organização visual, responsividade e experiência do usuário.

A proposta foi simular um cenário real de divulgação comercial, aplicando conceitos de desenvolvimento web para criar uma interface funcional, clara e atrativa.

---

## 🚀 Tecnologias Utilizadas
- HTML5  
- CSS3  
- JavaScript  

---

## 💡 Funcionalidades
- Exibição de produtos de forma organizada  
- Interface responsiva (adaptada para mobile e desktop)  
- Estrutura de navegação simples e intuitiva  
- Interações básicas com JavaScript  

---

## 🎯 Objetivo do Projeto
Aplicar, na prática, conceitos fundamentais de desenvolvimento front-end, como:
- Estruturação semântica com HTML  
- Estilização e responsividade com CSS  
- Manipulação de elementos com JavaScript  
- Organização de layout com foco em experiência do usuário  

---

## 📱 Responsividade
O projeto foi desenvolvido com foco em adaptação para diferentes dispositivos, garantindo uma boa experiência tanto em telas menores (mobile) quanto em desktops.
